Live Coinbase order book + execution simulator

Streams BTC and ETH Level 2 market data straight from Coinbase, calculates liquidity metrics in real time, and estimates how hypothetical orders would fill. Simulated only — no real trades are placed.

How it works

Two separate implementations share one design:

Python engine (the repo)

Price-time-priority limit order book (Decimal, SortedDict, FIFO queues), a Coinbase WebSocket consumer, a synthetic matching engine + FastAPI, a Rich terminal dashboard, unit tests, and a 100k-order benchmark.

synthetic orders → matching engine → fills / P&L / API

This static demo (the browser)

Connects to the public Coinbase WebSocket directly, mirrors the book per product, computes analytics, and estimates hypothetical fills. Read-only market data; the browser uses IEEE numbers for estimates while Python is the precision implementation.

Coinbase WS → parser → per-product book → metrics → view

Vercel serves this static page; it does not run the Python engine.

Can’t reach the live Coinbase feed (some networks block WebSockets).
